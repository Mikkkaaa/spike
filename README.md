# Spike

Учебные практические занятия по дисциплине «Стартап в информационных технологиях» (Институт перспективных технологий и индустриального программирования, кафедра индустриального программирования). Преподаватель: Адышкин Сергей Сергеевич.

**Стартап Spike** — Telegram Mini App, который по данным Яндекс Вордстата оценивает, на сколько рекламные кампании (свои и конкурентов) подняли поисковый спрос, с доверительным интервалом и без доступа к рекламным кабинетам.

## Структура

| Папка | Что внутри |
|---|---|
| [practice_1](practice_1/) | Практика №1. Название, слоган, УТП, логотип, бренд-борд. Отчёт: [Практическое_занятие_1_Spike.md](practice_1/Практическое_занятие_1_Spike.md) |
| [practice_3](practice_3/) | Практика №3. Лендинг: исходники в `src/`, сборка `build.py`. Отчёт: [Практическое_занятие_3_Spike.md](practice_3/Практическое_занятие_3_Spike.md) |

Новые практики добавляются папками `practice_N` рядом.

## Сборка лендинга (practice_3)

Нужны Python 3 и пакет `fonttools`.

```bash
pip install fonttools
cd practice_3
python3 build.py                      # собрать dist/
python3 -m http.server 8000 -d dist   # открыть http://localhost:8000
```

Папка `dist/` генерируется сборкой и в репозиторий не входит.
