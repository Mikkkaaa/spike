# Spike brand (общие материалы)

Единственная копия бренд-материалов. Практики ссылаются сюда, а не копируют файлы к себе.

| Что | Где |
|---|---|
| Логотипы (SVG и PNG, 5 вариантов) | `logo/` |
| Шрифты Inter и JetBrains Mono (TTF, лицензии OFL) | `fonts/` |
| Цвета и шрифтовые стеки | `tokens.css`, `tokens.json` |

Описание и правила использования: [practice_1](../../practice_1/Практическое_занятие_1_Spike.md), разделы 7.1–7.3.

Не править файлы в `practice_*/dist/` или других копиях: менять только здесь.
